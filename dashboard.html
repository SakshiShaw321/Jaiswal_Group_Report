What's missing — and why it matters more than what's here

Data gap
Sales, purchase and expense registers are currently empty (0 rows each) in sales_transcation.xlsx, purchase_transcation.xlsx and expense.xlsx. This dashboard is built entirely from the two ledgers that do have data — stock and customer/outstanding — so it can show what the business holds and what it's owed, but not yet sales velocity, purchase cadence, stock turnover days, or true operating margin. Once transactions are logged, this dashboard is designed to extend into revenue trends, best-selling SKUs, supplier payment cycles and real P&L margin — the structure below is ready for it.

Excel Converter — Purchase & Sales

Drop in purchase_transcation.xlsx or sales_transcation.xlsx (or any workbook with a similar layout) to preview it as a clean table, see instant totals, and export a normalised .xlsx workbook. Everything runs in your browser — no file is uploaded anywhere.

AI Bill Extractor Gemini

Upload a purchase bill (PDF) and Gemini extracts these 12 fields per line item: Purchaser Invoice No, JG Invoice No, Purchase Date, Supplier Name, Product Category, Item Name, HSN Code, Quantity, Rate (Per Unit), CGST, SGST, Total Amount. It reads the bill's own labels (e.g. "Original Invoice No.", "Purchase No.", "ITEMS", "HSN", "QTY.", "RATE") and leaves Product Category / CGST / SGST / Total Amount blank when the bill doesn't state them. Extracted rows load straight into the Purchase register below for export.

Sandbox note
This calls Gemini's API directly from the browser (generativelanguage.googleapis.com). That works when this file is opened directly in a normal browser or hosted on your own site, but the claude.ai artifact preview sandbox blocks direct calls to external APIs — inside that preview you'll see a network error instead. Your API key is stored only in this browser's local storage if you tick "Remember", and is sent only to Google's Gemini endpoint, never anywhere else.

How it works
The converter reads the first sheet of whatever workbook you drop in, shows the first 200 rows as a preview, and totals any column named Total Amount, Rate × Quantity, or similar. Use Download Excel (.xlsx) to save a proper spreadsheet, or Copy as JSON to paste the rows elsewhere. Nothing is sent to a server — parsing happens entirely in this browser tab via SheetJS. .xlsx isn't on the claude.ai artifact sandbox's allowed download list, so inside that preview the button falls back to a direct browser download, which only completes when this file is opened outside the sandbox (locally, or self-hosted) — same as the Gemini extractor above.
